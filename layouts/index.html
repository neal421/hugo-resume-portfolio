Hugo + GitHub + Netlify Workflow

How to Edit & Publish Your Site

Step 1

Edit Your Flat-File Resume Data

All text, experience bullets, skills, and links live in a single clean YAML file—no HTML or database required:

~/hugo-resume-portfolio/data/resume.yaml

Site-level settings (like your final domain name) live in hugo.toml.

Step 2

Push Your Repo to GitHub

Create a new repository on GitHub (e.g., hugo-resume-portfolio), then push from your terminal:

git remote add origin https://github.com/YOUR_USERNAME/hugo-resume-portfolio.git
git branch -M main
git push -u origin main
Step 3

Connect Netlify for Instant Publishing

  1. Log in to app.netlify.com and click Add new site → Import an existing project.
  2. Select GitHub and pick your repository.
  3. Netlify automatically reads the included netlify.toml file (which configures hugo --gc --minify and publishes public/).
  4. Click Deploy site. Every future git push will automatically update your live website in seconds!
